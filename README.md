# 🤖 AI Interview Tool

An AI-powered mock interview platform that helps users practice technical interview questions and receive instant feedback.

## ✨ Features

- 🎤 Mock interview interface
- 🤖 AI-generated feedback
- 📊 Answer scoring
- ⚡ FastAPI backend
- ⚛️ React + Vite frontend
- 🎨 Clean and responsive UI

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- FastAPI
- Python

## 📂 Project Structure

```
AI Interview Tool/
│
├── frontend/
└── backend/
```

## 🚀 Run Locally

### Backend

```bash
cd backend
pip install -r requirements.txt
python main.py
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
